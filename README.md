# NIGHTWATCH: The Last Shift

Game horor survival berbasis HTML, CSS, dan JavaScript. Tidak membutuhkan server atau instalasi.

## Cara menjalankan
1. Download/clone repository.
2. Buka `index.html` di browser modern (Chrome, Edge, Firefox).
3. Klik **MULAI SHIFT**. Gunakan layar penuh untuk pengalaman terbaik.

## Cara bermain
- Bertahan dari 12 AM sampai 6 AM.
- Gunakan **CAMERAS** untuk memantau pergerakan makhluk.
- Tutup **LEFT DOOR / RIGHT DOOR** saat ancaman mendekat.
- Gunakan **LEFT LIGHT / RIGHT LIGHT** untuk memeriksa lorong.
- Listrik akan habis lebih cepat jika terlalu banyak perangkat aktif.
- Keyboard: A/D = pintu kiri/kanan, Q/E = lampu kiri/kanan, Space = monitor, M = mute, Esc = tutup monitor.

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`, `README.md`, `LICENSE`, dan `.nojekyll`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu Save.
6. Tunggu proses deploy, kemudian buka URL GitHub Pages yang diberikan.

## Catatan
- Game ini original dan hanya terinspirasi dari genre survival-horror kamera-keamanan. Bukan produk resmi atau salinan Five Nights at Freddy's.
- Watermark **ABELINO PUTRA** ditampilkan di dalam game.
- Efek suara dibuat menggunakan Web Audio API. Browser mungkin meminta interaksi pertama sebelum audio aktif.
- Google Fonts digunakan untuk tipografi jika koneksi internet tersedia; game tetap berjalan tanpa koneksi.

## Kustomisasi
Edit judul, teks, warna, dan watermark di `index.html`. Untuk mengubah watermark, cari teks `ABELINO PUTRA`.
